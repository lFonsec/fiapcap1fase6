### Dataset utilizado
Os Datasets utilizados são o "Human Bone Fractures Image Dataset (HBFMID)" que se encontra em: https://www.kaggle.com/datasets/orvile/human-bone-fractures-image-dataset-hbfmid, e o segundo é o Brain-tumor encontrado em: https://www.kaggle.com/datasets/ultralytics/brain-tumor


### Brain tumor
Um conjunto de dados de detecção de tumores cerebrais consiste em imagens médicas de ressonância magnética ou tomografia computadorizada, contendo informações sobre a presença, localização e características dos tumores cerebrais

Possui 893 imagens de treinamento e 223 imagens de validação

### Human Bone Fractures Image Dataset (HBFMID)

Este conjunto de dados, o Human Bone Fractures Multi-modal Image Dataset (HBFMID), é uma coleção de imagens médicas (raios X e ressonância magnética) focada na detecção de fraturas ósseas em várias partes do corpo humano

Possui 449 images de treinamento e 128 imagens de validação
